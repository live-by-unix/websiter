__PROJECT__ — distributed workers

This app runs multiple independent worker processes:

  • DatabaseWorker — data access over IPC
  • AuthWorker — authentication (calls DatabaseWorker via IPC)
  • EmailWorker — event subscriber

Try it

curl localhost:8080/api/users
curl -X POST localhost:8080/api/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"alice","password":"demo"}'
curl localhost:8080/api/workers

Inspect processes: websiter workers list
